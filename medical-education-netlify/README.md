# აკადემია — Netlify-ის ვერსია

სამედიცინო განათლების კოორდინატორის დახურული სამუშაო სივრცე. კოდი განკუთვნილია მხოლოდ Netlify-ზე ასატვირთად. Vercel-ის ან Cloudflare-ის კონფიგურაცია ამ პაკეტში არ არის.

დასაწყებად გახსენით **NETLIFY-INSTRUCTIONS.md** — სრული ქართულენოვანი ინსტრუქციაა.

შედის: უნივერსიტეტები და მემორანდუმები, აუდიტორიებისა და სალექციო განრიგების დაგეგმვა, ექიმები და ქულები, რეზიდენტურა, დავალებები და ანგარიშები, უსგ ტრეკერი და წყაროების ადმინისტრირება. ფინანსური განყოფილება გამორთულია. მუქი თემა საწყისად ჩართულია.

შესვლა: მხოლოდ ერთი ადმინისტრატორის ელფოსტა და პაროლი. ახალი ანგარიშების რეგისტრაცია არ არსებობს. ჩანაწერები ინახება Netlify Database-ში, ფაილები — Netlify Blobs-ში. ახალი ფაილის ლიმიტია 3 მბ. ეს სერვერის მოთხოვნის ზომის ფარგლებში მუშაობისთვისაა.

მონიტორინგი: Netlify-ის Scheduled Function ყოველდღე თბილისის 08:00-სა და 18:00-ზე იწყებს ფონურ შემოწმებას. კითხულობს ჩართულ რეესტრს, მათ შორის პანელიდან დამატებულ ბმულებს. ახალი ორგანიზაციების ზოგადი ინტერნეტძიება ავტომატურად არ ხდება. რიცხვები და აკრედიტაცია წყაროს გარეშე არ გამოიცნობა.

```sh
npm ci
npm run check
npm test
npm run build
```

Netlify-ზე რეალური განთავსება და დაგეგმილი გაშვების დადასტურება საჭიროებს თქვენს ანგარიშს. ეს ZIP არ წარმოადგენს უკვე გამოქვეყნებულ ახალ საიტს. ადგილობრივი აწყობა და ტესტები გადამოწმებულია; ანგარიშის მონაცემებს, პაროლებსა და ძველ სამუშაო ჩანაწერებს ZIP არ შეიცავს.
